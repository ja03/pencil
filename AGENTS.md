### Issue tracker

Issues are tracked in GitHub Issues for `ja03/pencil`, through the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the five default labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Roadmap

Before picking up an issue, read `docs/agents/roadmap.md`: how to find the frontier (the next unblocked issue), rules every issue follows, and per-issue gotchas.
